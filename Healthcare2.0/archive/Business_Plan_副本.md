# HealthCare: 营养师数字化复购增长引擎 - 项目计划书 (BP) - v5.2

## 1. 执行摘要 (Executive Summary)
HealthCare 是一款专为营养师和健康管理人员设计的数字化生产力工具。我们通过“库存校准”与“健康改善闭环”这一独特切口，解决保健品行业**“高获客、低复购、服务难量化”**的核心痛点。我们的目标是让营养师的管理上限提升 10 倍，同时让客户的健康改善真正可见、可感、可复购。

## 2. 问题痛点 (Problem Statement)
*   **营养师侧**：管理 20 人已是极限。脑力过载，无法精准获知每个客户的服用进度，复购全靠“硬推”，缺乏专业说服力。
*   **客户侧**：买了不吃、吃了没感。缺乏依从性，无法直观看到改善效果，导致保健品成为“智商税”。
*   **行业侧**：公域流量枯竭，私域资产沉淀难。营养师与客户的信任关系脆弱，缺乏数字化抓手。

## 3. 解决方案 (The Solution)
HealthCare 打造了基于 **Uni-app (万能模具)** 与 **腾讯云 PostgreSQL (中央大账本)** 的全端数字化引擎：
*   **全能手机移动店 (小程序双模式)**：客户极速打卡、传体感；营养师随时随地接收预警、快速批改方案。
*   **总店深度监控室 (Web Admin)**：仅限营养师/管理员使用，提供大屏深度复盘、批量导出数据、复杂配方建模等高级功能。
*   **库存校准引擎**：系统自动预警 -> 客户自主对齐 -> 自动闭环库存。将“催单”转化为“专业服务”。
*   **双轨制健康报告**：主观体感（睡眠/精力）+ 客观指标（体重/血脂）对比图。用数据证明效果，驱动续费。

## 4. 产品特色 (Product Highlights)
*   **Uni-app 极致分发**：一次开发，覆盖小程序双模式与 Web 后台，极大降低研发成本。
*   **腾讯云 PostgreSQL 中央大账本**：金融级关系型数据库，确保业务数据的绝对准确与安全隔离。
*   **SaaS 多租户支持**：底层支持多租户隔离，满足从个人工作室到连锁机构的阶梯式扩张需求。
*   **资产所有权隔离**：通过 Gitee 代码仓库托管核心业务逻辑，确保机构商业资产的安全。

## 5. 商业模式 (Business Model)
*   **SaaS 订阅费**：面向个人营养师或工作室收取年度服务费。
*   **品牌定制版 (B2B)**：为保健品品牌方提供全链路数字化管理方案。
*   **增值服务**：未来可扩展至内嵌商城分成、数据分析报告、专业营养课程分发等。

## 6. 竞争优势 (Competitive Advantage)
*   **数据粘性**：客户在系统内沉淀的 3-6 个月健康趋势图，是竞品无法带走的资产。
*   **效率红利**：通过极致的 UI/UX 设计，将服务成本降低 90%，规模效应显著。
*   **去中心化信任**：我们不直接触碰交易，而是赋能营养师，做他们背后最坚实的盾牌。

## 7. 发展路线图 (Roadmap)
*   **Phase 1: MVP 验证 (1-3月)**：跑通中央大账本、小程序双模式打卡与预警闭环。
*   **Phase 2: 效率增强 (4-6月)**：上线 Web 管理中台，支持深度复盘、批量导出与复杂配方模板。
*   **Phase 3: 闭环生态 (7-12月)**：开放 API 对接主流商城、引入 AI 指标自动识别录入、探索品牌联名版。
