# HealthCare Pro 核心业务流程测试清单

## 测试环境准备
- [ ] 确保云函数正常部署
- [ ] 测试账号：营养师账号 + 至少3个客户账号
- [ ] 基础数据：产品库、配方、库存初始化

## P0 核心流程测试

### 1. 用户登录与权限验证
- [ ] 营养师登录成功，进入工作台
- [ ] 客户登录成功，进入首页
- [ ] 权限隔离：客户无法访问管理端
- [ ] 权限隔离：营养师只能管理自己的客户

### 2. WROM评分计算流程
- [ ] 客户完成打卡任务，触发WROM重新计算
- [ ] 依从性评分：基于任务完成率正确计算
- [ ] 库存评分：基于库存天数正确计算
- [ ] 体感评分：基于体感趋势正确计算
- [ ] 互动评分：基于活跃度正确计算
- [ ] WROM总分正确更新到用户表

### 3. 库存管理流程
- [ ] 打卡时自动扣减对应产品库存
- [ ] 库存扣减记录正确写入日志
- [ ] 低库存预警（<5天）正确触发
- [ ] 客户端库存页面实时显示剩余数量
- [ ] 营养师端能看到客户库存状态

### 4. 订单处理流程
- [ ] 客户发起补货申请，生成订单
- [ ] 营养师端显示待处理订单
- [ ] 营养师确认发货，更新订单状态
- [ ] 客户确认收货，增加个人库存
- [ ] 库存增加记录正确写入日志

### 5. 预警机制流程
- [ ] WROM<60时触发高风险预警
- [ ] RPS<60时触发复购风险预警
- [ ] 库存不足时触发低库存预警
- [ ] 连续未打卡触发断签预警
- [ ] 预警通知正确推送到营养师端

## P1 重要功能测试

### 6. 数据展示完整性
- [ ] 营养师工作台显示正确统计数据

- [ ] 低库存客户列表正确显示
- [ ] 今日打卡率正确计算
- [ ] 客户端WROM评分正确展示

### 7. 跨端数据一致性

- [ ] 库存变化后，双端数据一致
- [ ] 评分更新后，双端显示一致
- [ ] 订单状态变化后，双端状态同步
