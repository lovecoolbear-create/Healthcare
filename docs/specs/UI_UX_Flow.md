# HealthCare 项目 UI/UX 交互流程设计 - v1.0

基于 PDR 定稿，我们将系统分为 **营养师 Web 端** 和 **客户微信小程序端**。以下是核心页面设计方案。

---

## 1. 营养师 Web 工作台 (Practitioner Web Portal)

### 1.1 核心 Dashboard (首页)
**设计理念：解决“脑力过载”，只处理异常。**
*   **A 区：红色警报 (Risk Alert)**
    *   异常打卡：连续 24h 未打卡客户列表。
    *   负面反馈：体感反馈“变差”或“无改善”的客户（置顶显示）。
*   **B 区：待补货机会 (Replenishment)**
    *   系统自动计算库存 ≤ 3 天的客户，点击“发起校准”可一键发送链接至客户微信。
*   **C 区：今日随访 (Daily SOP)**
    *   根据 3-7-14 天周期自动排出的随访名单。
*   **D 区：指标动态 (Metrics Update)**
    *   提醒哪些客户上传了新指标，点击查看趋势图。

### 1.4 营养师移动端极简视图 (Mobile Slim Workflow)
**设计理念：随时随地消灭红点。**
*   **核心功能**：只保留 Dashboard 的 A、B、D 区。
*   **交互流**：点击预警卡片 -> 自动生成话术 -> 跳转微信。
*   **严禁操作**：移动端不提供复杂的指标录入与产品库配置功能。

### 1.2 客户管理中心 (Client List)
*   **多维搜索**：支持按标签（如：高血压、备孕、严重漏服）、最后联系时间、库存状态筛选。
*   **批量操作**：一键群发随访模版（跳转微信）。

### 1.3 客户详情页 (Client Detail)
*   **左侧：健康档案**。包含历史报告、指标趋势图。
*   **中间：实时方案与库存**。可直接修改剂量、手动校准库存。
*   **右侧：随访小贴条 (Private Notes)**。时间轴展示，支持添加“混合标签”。

## 2. 客户微信小程序 (Client WeChat Mini Program)

### 2.1 极速对齐 (The Daily Action)
**设计理念：3 秒完成 1% 的坚持。**
*   **智能打卡卡片 (Time-Slot Card)**：
    *   **动态显示**：基于当前时间自动弹出“晨起/随餐/睡前”任务包。
    *   **交互**：显示产品名（如：益生菌 + VC），一个巨大的确认按钮。
*   **库存同步弹窗 (Weekly Calibration)**：
    *   **频率**：系统设定每周自动弹出。
    *   **交互**：左右滑动条快速对齐实物剩余粒数。
*   **今日精力滑块 (Daily Energy)**：
    *   **位置**：打卡成功后的二级反馈。
    *   **交互**：1-10 分滑动选择，系统自动生成体感趋势图。

### 2.2 好转进度条 (The Mirror)
**设计理念：可视化好转，建立信心。**
*   **双轨趋势图 (Dual-Track Charts)**：
    *   **主观线**：精力/睡眠/情绪的平滑趋势曲线。
    *   **客观线**：体重/腰围的历史变化。
*   **对比墙 (Photo Comparison)**：
    *   **隐私控制**：支持隐私加密预览，仅在确认后展示。
*   **科普动态 (Insights)**：
    *   **动态更新**：显示如“线粒体修复进度”等科普语言描述。

### 2.3 数字化分身 (The Human Touch)
**设计理念：随时触达，专业陪伴。**
*   **置顶方案 (Pinned Protocols)**：
    *   **内容**：显示当前调理目标、禁忌列表、喝水进度条。
*   **专业投喂 (Practitioner Insights)**：
    *   **内容**：营养师针对该客户推送的小贴士/短文。
*   **联系按钮 (Call)**：
    *   **操作**：一键呼叫或复制微信号。

---

## 3. 核心交互流 (Core User Flow)

### 3.1 绑定流 (Onboarding)
1.  营养师展示个人二维码。
2.  客户微信扫码，进入小程序授权。
3.  营养师 Web 端收到通知，录入客户初始库存与方案。
4.  绑定成功。

### 3.2 补货流 (Replenishment Flow)
1.  系统监测到库存临界点。
2.  营养师 Dashboard 提醒。
3.  营养师点击“发送购买链接”。
4.  客户小程序收到通知，点击链接完成支付。
5.  **到货反馈**：客户收到快递后，在小程序点击“我已收到货”。
6.  **自动更新**：系统按购买规格自动增加库存，重算预警时间，并通知营养师“XX 客户已补货成功”。

### 3.3 校准流 (Calibration Flow)
1.  营养师怀疑库存不准，发起校准。
2.  客户小程序首页弹出浮窗。
3.  客户滑动条输入实物数量（如：剩 12 粒）。
4.  系统自动重算库存，预警日期更新。
